# 授权对象配对关系训练 v1

## 结论

本轮完成新数据、单边捷径审计、12个固定对照、三种子小型头训练和独立核验。**配对损失提高了召回，但误报代价过高，未达到可部署的泛化改善。**

普通BCE头的测试召回均值13.89%，配对头43.52%；FPR同时从8.95%升至25.93%。同一新测试集上，72个同正文对照分别只有2/3/2对与5/6/5对同时判对。36个完整目标四组合，两种方法所有种子均为0组全正确。不部署、不继续围绕本测试集调参。

## 数据设计

[运行前方案](../../../s6/prompt_injection/AUTHORIZATION_RELATION_V1_ZH.md)。每个场景完整构造授权A/B与操作A/B四组合：相同对象正常，不同对象风险。任务与正文均提到两个ID，但明确区分操作对象与排除/参考对象。

每个任务文本和每个正文文本都分别出现在正常、风险目标样本中，单边标签严格各半。仅任务、仅正文模型在新训练/校准/测试的目标子集准确率均为50%，数据审计和预测核验均通过。

新540条包含108个四组合（216对）与108条引用。任务族、措辞模板和具体ID不跨划分；纳入旧240＋60条后的字符3—5元TF-IDF跨划分最高相似度0.357307，小于预设拒绝界限0.88。

**这540条为程序构造、未经用户逐条审核的英文数据。** 字面ID匹配与明确引用构成标签依据，不引入别名、代词、含糊授权。旧60条的人工审核不等于本批有人类标签。这是合成任务组/措辞留出实验，不是自然场景或外部盲测；低词面相似度不证明语义独立。

旧240条与已审核60条仅在头与阈值冻结后作曝光诊断，不参与学习、校准或选型。本次540条此后也属于已曝光数据。

## 方法

- 冻结本地MiniLM和DeBERTa NLI，不微调编码器，不下载模型。
- 4个C=1逻辑回归控制：仅正文、仅任务、联合MiniLM、6个NLI概率。
- 联合MiniLM特征接64单元tanh MLP，类别平衡BCE；AdamW，lr=0.001，weight decay=0.001，300个全批次CPU训练步骤。
- 配对MLP使用相同初始化与设置，额外加入`0.5 * mean(softplus(0.5 + safe_logit - risk_logit))`；只使用训练中的同正文授权对照。
- BCE与配对各跑2026/2027/2028三个种子，不选最佳种子、不按测试早停。训练种子不代表独立数据重复或统计显著性证据。
- 另有冻结NLI原0.5阈值与上一轮已冻结低阈值两个对照，共12个方法/种子组合。
- 新监督头只在新校准集定阈值：FPR≤5%下最大召回，依次以更低FPR、更高阈值打破平局。校准正常72条，最多允许3条误报，不保证测试FPR。
- 模型只接收文本特征；用于标签审计的`audit_only_*`对象ID字段在编码前剥离，未作为模型特征或预测规则。
