# Code 注释语境信号：开发与确认（探索性）

候选方法为 P1 规则或通用注释重定向信号命中即复核。信号只读 Python 注释，不解析可执行代码。开发集使用上一轮标准库来源；确认集在信号实现前冻结，来自 100 个不同的 scikit-learn 文件及 8 种新措辞。未接入 P1/P3 授权。

确认集的 8 种预先写定措辞中，注释信号完整检出 5 种、完全漏掉 3 种；前置和后置变体共享同一来源，因此 124/200 不是 124 个独立攻击。测试后没有修改信号或重跑确认。100 条干净确认代码未被该新信号误报，但这个样本量不足以证明实际误报率为零。

原始 scikit-learn 代码片段只保留在本地，不纳入 Git；协议记录 100 个文件标识、来源哈希和数据哈希。结果 CSV 不含代码正文。

## 解释边界

本实验是合成代码注释的离线检测评估，不是真实 LLM 代理攻击成功率；只有一套新代码来源、100 条干净确认样本，误报率每条波动 1 个百分点。确认模板虽在实现前冻结，但由研究者事先编写并知晓，不是严格盲测。候选方法对注释中的明确任务重定向有效，但尚未评估文档字符串、其他语言、真实仓库攻击或端到端代理行为。不要与 BIPIA Code 或上一轮标准库结果合并平均，也不要直接接入工具授权。
