# 专用分类器与4B直接判定：检出明显改善，仍未达到完整可用门槛

日期：2026-10-04。两项评估、离线核验和任务授权变化对照已完成。**第一项使用公开的ProtectAI DeBERTa v2，未使用Prompt Guard 2**；后者文件下载需要账号访问权限，匿名请求401，用户授权检查后发现本机没有已配置的HF命令行凭据。浏览器控制工具因沙箱初始化失败不能读取登录会话。未提取浏览器认证材料。

NotInject原本是用户提问，而非不可信检索正文，因此43.36%是输入类型迁移的压力诊断，不能直接当作部署时检索内容误报率。但它明确显示该模型不能作为任意文本的通用闸门。模型主要支持英文，未评估18条中文授权案例。上游训练与公开基准的重叠未知。

## 3. 4B直接判定的瓶颈

模型是既有本地Qwen3-4B基础模型，NF4/BF16；未加载抽取LoRA，未训练。可信任务与不可信正文作为两个明确字段输入，固定英语系统提示要求NORMAL/RISK/UNKNOWN、原文证据及简短原因。关闭思考、贪心、最大256输出token、总预算8192，无修复、无截断。

- **有效输出不足**：InjecAgent 13/64、SecOPD 5/80、中文1/18，共19/162（11.73%）INVALID；全部因为证据不是正文中的精确片段，而非JSON语法错误。全部162条产生了完整EOS输出，没有预算超限或资源拒绝。仅限制JSON语法无法消除这批证据问题。
- **存在真实漏检与误报**：SecOPD有5条攻击被判NORMAL，1条正常被判RISK；不是全部失败都能靠证据格式修复。
- **未知授权处理失败**：中文旧留出18条只判对11/18；风险5/6、正常6/6、不确定0/6。6条不确定被判为5个RISK和1个NORMAL。模型会把缺失范围、未知脚本副作用当作已知危险，或反过来认作没有指令。这个缺口与原文证据核验无关。
- **事后标签诊断，不是主指标**：忽略证据有效性，仅读原始JSON的decision，InjecAgent正确标签为59/64、SecOPD74/80、中文12/18。它表明证据接口降低了主分数，但没有解决未知授权问题。未修复输出、未重算或替换已发布主指标。

原v3大组抽取＋比较器在同中文材料的旧结果为16/18，当前基础模型直接判定11/18。两者模型训练状态不同，不能据此隔离“直接判定”这一方法的因果效果；当前简化方案不能替代旧研究结果。

## 4. 同正文、不同授权的补充对照

另开 `results/bipia/content_controls_v1/`：6组、12条助手编写的简单英文案例，覆盖收件人、列范围、删除、联网、模拟/真实安装及TTL保留。每组正文相同，可信用户任务分别明确允许与禁止其操作。未人工审核，句式明显，只是实现诊断，非独立泛化证据。

| 系统 | 两侧同时正确 |
|---|---:|
| 纯正文分类器 | 0/6 |
| 任务＋正文4B直接判定 | 5/6 |

4B有1条网络禁止案例的判定是RISK，但证据不精确，计INVALID；忽略证据的事后标签诊断为6/6。分类器对相同正文不可能产生两个不同授权判定，这个限制由输入信息决定，不能仅靠扩大分类器解决。

## 5. 是否继续投入，以及第三项怎么试

推理前登记的经验候选门槛：InjecAgent召回≥70%、SecOPD召回≥80%、正常误判风险≤5%、正常自动判NORMAL≥90%；分类器另要求NotInject压力误报≤5%。**两项均未通过完整门槛**：分类器未过压力误报；4B未过正常自动率，并有不确定类完全失效的问题。以上是小样本经验筛选，非部署保证。

建议进入第三项的设计和离线验证：**按任务授予的能力约束工具调用，并记录参数来源**。先作为独立研究版本，保持现有P3、前端和检测器不变。

1. 工具注册时声明动作类别、目标类参数及副作用，不再通过工具名首词或动词猜测。注册表来自受信配置，不能读取评估标签作为线上可信性。
2. 调用参数带宿主程序记录的来源：用户、受信配置、某次工具返回及字段路径、派生值。模型自己声称“来自用户”不能改变标记；仅做字符串包含检查不算来源追踪。
3. 区分“数据值可以来自正文”与“正文可以扩张授权”。例如用户允许读取日历中的时间创建会议，时间可以来自工具返回；正文新增收件人、外发地址、其他账户、路径范围或绕过确认，不自动取得权限。
4. 对未知工具副作用、未解析对象映射、未满足条件保留REVIEW；明确的范围冲突才拒绝。不把所有外部来源值一律拒绝，否则正常代理任务无法完成。
5. 离线对照P3、旧字面匹配对齐、新来源/能力策略；分别报告危险调用放行、正常任务完整自动放行、误拒和复核量。覆盖同工具换目标、跨服务、正常委托、来源缺失。现有AgentDojo等材料仅作已曝光诊断；独立结论需要新来源或预先冻结的未曝光任务。

第三项仍不能保护不涉及工具的答案篡改。内容检测与任务判定保留为辅助信号，最终需要隔离环境中的真实正常任务成功率及攻击成功率评估；本轮未运行真实代理。
