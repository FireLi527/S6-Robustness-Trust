- 每类只有6条，相差一两条就会改变结论，不能据此对各规模排序。

## 结论与下一步

v3 规范加上 v3 重新训练，在曝光过的验证集上改善了字段抽取，这与“统一标注规范有助于学习”的假设一致。但这里的比较不是独立检验。按预先登记的方案，下一步应**只打开一次**密封留出组：比较 v3 各配置与 v1 的28组适配器，同时报告抽取指标和判定指标。
