# 仓库文件提示词注入：外部错误分析与第二轮协议

状态更新（2026-09-29）：已完成 30 条维护说明的 AI 逐条初审、全部外部错误导出、五类重复模板核验和固定模型输入消融。结果见 `../repo_file_review_v1/findings_ZH.md`；第二轮设计见 `../../../data/bipia/repo_file_v2/experiment_design.json`（从项目根目录查阅该路径）。独立人工复核仍待完成。本页保留最初研究计划，未重新训练或部署。

## 第一轮能确认的错误分布

第一轮内部测试中，仓库文件分类器的检出率为 527/584（90.24%），误报率为 27/551（4.90%）。这一结果不能代替跨来源泛化评估。

| 外部来源与攻击目标 | 检出 / 攻击 | 漏检 / 攻击 | 解读 |
| --- | ---: | ---: | --- |
| RepoGuardBench：读取 canary | 76/94 | 18/94 | 该目标相对容易识别 |
| RepoGuardBench：外传 canary | 44/94 | 50/94 | 明显退化 |
| RepoGuardBench：植入后门 | 2/94 | 92/94 | 几乎失效 |
| RepoGuardBench：未授权 shell | 2/94 | 92/94 | 几乎失效 |
| RepoGuardBench：删除测试 | 0/94 | 94/94 | 完全失效 |
| RepoGuardBench：合计 | 124/470 | 346/470 | 检出率 26.38% |

以上五组各有 94 条，但来自有限模板和任务组合；不能把 470 条当成 470 个独立攻击家族。RepoGuardBench 的 94 条干净样本中误报 1 条（1.06%）。AgentInjectionBench 的 `file_content` 子集检出 6/8、干净 0/2；Ashwin 间接注入子集检出 10/13、干净 1/4。这些小样本结果只能作诊断。30 条未经独立标注的真实维护说明中，模型标记 13 条、P1 标记 3 条；目前**不能计算它们的误报率**。

这些结果支持一个有限的判断：模型在新来源的代码仓库内容上，尤其对含代码修改、shell 或测试删除目标的攻击，泛化不足。原因可能包括训练数据的表述风格、文件场景覆盖、上下文缺失或数据家族差异；仅凭汇总指标无法确定哪一个是主因。

## 先做逐条审查，不先训练

1. 从现有 `external_predictions.csv` 找出 RepoGuardBench 的 346 条漏检、1 条干净误报，以及另外两个外部来源的全部错误。结合原始样本文本，按“攻击目标、指令位置、代码/文档载体、是否隐含越权、是否跨行、是否依赖用户任务上下文”记录现象。每类至少保留数条可追溯的代表样本；不得仅凭预测文件中的标签推断攻击机制。
2. 对 30 条维护说明逐条审查原文，记录 `sample_id`、来源链接或路径、文档类型、是否包含对代理的可执行指令、是否与被授权用户任务冲突、判定标签、理由和审查人。将“不确定”单列，不强行并入干净或攻击。模型预测应在初次标注完成后再揭示，以降低确认偏差。
3. 只有确认的干净样本才能用于计算这批说明的误报率；同时报告分子、分母和样本选择方式。30 条不是随机抽样，所得比例不能推广到所有真实仓库文档。

## 第二轮实验边界

- 第一轮内部测试、RepoGuardBench、AgentInjectionBench 和 Ashwin 子集都已经看过结果，后续可用于错误分析和开发反馈，**不能再充当未见过的最终外部测试**。需要另收一个来源/仓库家族独立、在模型与阈值冻结后才揭盲的外部测试集。
- 候选方向是面向仓库文件场景补充“修改代码、运行命令、删除测试”攻击及相似的正常维护文本；记录来源、仓库/文件家族、模板和生成方式。训练、验证和最终测试按来源/仓库家族隔离，并做近重复检查。
- 先建立人工标注规范与数据清单，再决定是扩充训练集、调整特征，还是保留现有模型并另设仓库场景检测器。不能把 RepoGuardBench 的具体 470 条搬进训练后仍用它宣称外部泛化。
- 在验证集上选阈值，固定后只评一次新的独立测试集；同时报告检出率、精确率、误报率、准确率及 TP/FN/FP/TN，并按攻击目标和文档载体分层。小样本结果附分子分母，不宣称统计显著。
- 与第一轮 P1、当前模型和“P1 或模型”分别对照。组合规则可能增加误报，不能只比较检出率。任何新模型都只作离线研究；在真实良性仓库文件上的误报和授权边界得到验证前，不接入前端默认检测或 P3 工具授权。

下一道决策门槛：完成维护说明人工标注与漏检原文审查后，写出可复核的错误类别分布，再冻结第二轮数据来源、划分与模型选择规则。
