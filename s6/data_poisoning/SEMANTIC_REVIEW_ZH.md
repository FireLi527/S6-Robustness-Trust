# 语义检测审查与修复（2026-09-11）

## 确认的问题

1. 旧 `fit_trusted_projection` 用五个独立 NCA 模型变换各自留出样本，再把向量拼成一个全局空间计算距离。不同模型的坐标/度量未对齐，跨折距离缺乏统一含义。已移除此路径，新 v0.5.0 直接使用原始 CLIP 特征。旧 NCA 实验不能证明 IP102 或特征本身是唯一性能瓶颈；本次没有重跑旧 IP102 以量化该问题的影响。
2. 旧前端冻结结果只校验检测器配置，未绑定候选清单。已加入全部候选清单 SHA-256，修改清单或检测器后不复用旧结果；实时检测缓存也绑定清单哈希。
3. 特征缓存未明确绑定嵌入模型。已增加模型/维度/预处理元数据，不匹配时失效；提取入口在缓存命中时也核验实际图片字节，拒绝伪造/过期哈希及越界路径。
4. 重复图片可能在交叉验证训练和验证折中同时出现，抬高置信度。当前明确拒绝重复 ID 或图片哈希，要求先解决重复数据，不静默计算有泄漏风险的分数。
5. 单类、单样本或无效特征会触发未处理的分类器/近邻错误。单类时分类器信号标为缺失，少于两张图片、零向量、非有限特征显式报错。
6. 前端仍描述旧 NCA 流程。已更新为当前原始 CLIP 检测，区分轻量交叉验证分类器与下游 ResNet18。

## 方法限制，不能靠修复代码消除

- 近邻和中心使用候选标签，逻辑回归也拟合候选标签；标签污染可以削弱参考统计。
- 相似类别、风格差异、模糊背景可能降低特征区分度，尚未用分组实验测量各因素贡献。
- REVIEW/QUARANTINE 分数不是已校准的投毒概率。0.62/0.75 是继承的阈值，没有按 STL-10 攻击结果调参。
- 候选清单与真值文件分离属于代码/文件协议，不是操作系统权限隔离。
- STL-10 的图像源于 ImageNet，不能声称预训练表示与这些图片完全无重叠。
- 本次切换同时改变数据集和去除投影，STL-10 与历史 IP102 指标差异不能全部归功于其中某一个改变。

## 验证

回归测试覆盖候选/真值隔离、正常与错误标签、重复图片、单类/单样本、无效特征、模型缓存失效、文件字节变化、清单版本失效、STL-10 分层划分。真实数据另经官方二进制校验、四组清单完整性评估及语义评估。
