判定方法与适用边界

三层结果应分别解读：内容风险、任务一致性和执行权限不是同一个问题。

P1 · RULES

快速规则筛查

对显式指令覆盖、角色劫持和数据外传模式进行加权匹配，速度快且证据可定位，适合作为稳定基线。

P2 · SEMANTICS

任务一致性补充

在提供用户真实任务时，用本地 MiniLM 比较内容与任务的语义关系，再与 P1 合成混合门控结果。

P3 · POLICY

工具权限兜底

对高影响工具、外部目标和不可信内容触发的调用实施阻断或人工复核，减少检测漏报转化为真实危害。

边界：本控制台是研究基线，不应将 ALLOW 解读为内容绝对安全。生产系统还需要隔离执行、最小权限、审计与针对业务数据的持续评估。
